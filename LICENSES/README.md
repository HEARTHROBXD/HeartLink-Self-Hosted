# Component licenses

- `MPL-2.0.txt`: previously published Flutter client and client-side Rust core revisions. Existing grants remain in force; proprietary distribution of later revisions is conditional on confirming the right to relicense every contribution.
- `AGPL-3.0-only.txt`: synchronization server.
- `Apache-2.0.txt`: shared protocol and SDK model packages.
- `CC-BY-4.0.txt`: project documentation.

The self-hosted synchronization service remains open source. Official-cloud-only modules will be developed separately after the official-cloud asymmetric protocol is refactored. Before a proprietary client release, complete the contributor-rights and dependency-license audit, retain all required notices, and publish corresponding source for any MPL-covered files that cannot be relicensed. This file describes intended boundaries but is not a substitute for the license texts or legal advice.
